# PDFConverter Bot

Telegram-бот на **aiogram 3** для конвертации изображений (JPG, PNG, WEBP и др.) в один компактный PDF-документ с автоматическим сжатием и сохранением порядка файлов.

---

## Особенности

* **Асинхронная архитектура**: Тяжелые операции обработки изображений и сборки PDF вынесены в отдельные потоки (`asyncio.to_thread`), что предотвращает блокировку Event Loop.
* **Умная подготовка изображений**:
  * Коррекция ориентации кадра на основе **EXIF-метаданных** (фотографии со смартфонов не переворачиваются).
  * Конвертация палитр (RGBA/PNG) в RGB для корректной сборки.
  * Настраиваемое сжатие JPEG и изменение размера (по умолчанию до 1200x1800 px) для минимизации размера итогового файла.
* **Устойчивость к сбоям**:
  * Повторные попытки отправки результата (`send_file_with_retry`) с обработкой `TelegramRetryAfter` и сетевых ошибок.
  * Сохранение временных файлов при неудачной отправке — пользователю не нужно загружать их заново.
* **Управление ресурсами**:
  * Ручная очистка временных файлов по команде `/clear`.
  * Автоматическое удаление временных каталогов `temp/{user_id}` после успешной отправки.
* **Учет статистики**: Интеграция с СУБД через **SQLAlchemy (AsyncIO)** для учета пользователей и операций конвертации.

## Стек технологий

* **Язык**: Python 3.11+
* **Фреймворк бота**: `aiogram 3.x`
* **Обработка графики**: `Pillow`
* **Сборка PDF**: `img2pdf`
* **База данных**: SQLAlchemy (Async Engine)
* **Логирование**: Встроенный модуль `logging`

## requirements.txt

* **aiogram** — асинхронный фреймворк для Telegram-бота.
* **pillow** — обработка и сжатие изображений, коррекция EXIF-ориентации (ImageOps).
* **img2pdf** — сборка сжатых графических файлов в PDF.
* **pikepdf** — дополнительная работа с структурами и оптимизацией PDF-файлов.
* **sqlalchemy** & **asyncpg** — асинхронное взаимодействие с базой данных PostgreSQL (для CRUD-операций с пользователями и логами конвертаций).
* **alembic** — управление миграциями базы данных.
* **python-dotenv** — загрузка переменных окружения (.env) с токеном бота и URL базы данных.
* **aiofiles** — асинхронное чтение и запись файлов на диск (полезно при сохранении и удалении в temp/)

## Быстрый запуск

### Вариант 1. Использование uv (Рекомендуется)

`uv` — быстрый менеджер проектов и зависимостей Python.

1. Клонирование репозитория:
   ```bash
   git clone [https://github.com/AnastasiyaBorisycheva/PDFConverter.git](https://github.com/AnastasiyaBorisycheva/PDFConverter.git)
   cd PDFConverter
    ```
2. Запуск проекта через uv:
Команда uv run автоматически создаст виртуальное окружение и установит все зависимости из pyproject.toml при первом запуске:
    ```Bash
    uv run main.py
    ```
### Вариант 2. Классический запуск (pip + venv)

1. Клонирование репозитория
    ```Bash
    git clone [https://github.com/ВашЛогин/PDFConverter.git](https://github.com/ВашЛогин/PDFConverter.git)
    cd PDFConverter
    ```
2. Создание и активация виртуального окружения:
    ```Bash
    python -m venv venv

    # Linux / macOS
    source .venv/bin/activate

    # Windows (PowerShell)
    .venv\Scripts\Activate.ps1
    ```

3. Установка зависимостей
    ```Bash
    pip install -r requirements.txt
    ```

4. Настройка переменных окружения
Создайте файл .env в корневой директории:

    ```Фрагмент кода
    BOT_TOKEN=your_telegram_bot_token_here
    DATABASE_URL=sqlite+aiosqlite:///./sql_app.db  # Или PostgreSQL
    ```

5. Запуск бота
    ```Bash
    python main.py
    ```

## Использование

1. Отправьте боту одно или несколько изображений (как фото или как документы).

2. Отправьте команду /convert (или сообщение, содержащее слово convert).

3. Бот сожмет изображения, соберет их в PDF и отправит итоговый документ.

4. Чтобы удалить загруженные файлы без конвертации, отправьте /clear.
